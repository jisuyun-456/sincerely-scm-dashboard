New Supabase Tables — 3 new sync jobs for TMS

tms_carrier_otif NEW

Per-carrier OTIF %, updated daily. Powers the Carrier OTIF Ranking widget.
snapshot_dateDATEPK part · daily snapshot
partner_nameTEXTPK part · e.g. "신시어리 (로젠)"
total_shipmentsINTshipments for this carrier today
on_time_countINTon-time deliveries (from OTIF table)
otif_pctNUMERIC(5,2)on_time_count / total * 100

tms_daily_volume NEW

How many shipments were sent / delivered each day. Powers Daily Volume bar chart.
dateDATE PRIMARY KEYshipment date (발송일 or 처리일)
sent_countINTshipments created on this date
delivered_countINT배송완료 confirmed on this date
pending_countINTstill active as of this date

tms_pod_aging NEW

POD status per shipment. Powers POD Aging buckets + exception alerts.
snapshot_dateDATEPK part · daily snapshot
shipment_idTEXTPK part · Airtable record ID
tracking_noTEXT운송장번호
delivered_dateDATE배송완료 date
pod_confirmedBOOLEANPOD received?
days_pendingINTtoday - delivered_date, null if confirmed
partner_nameTEXTcarrier for the exception badge
