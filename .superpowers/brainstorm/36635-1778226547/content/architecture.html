How should all this TMS data fit in?

Three structural approaches — pick the one that feels right

A

Multi-page — activate the nav

The existing Vault · TMS · WMS · Log header items become real page links. Home = current overview. TMS page = full TMS deep-dive (OTIF trend, carrier ranking, exceptions, volume, POD aging). WMS page = WMS-focused view.

Header nav:
Home TMS → WMS → Log →
TMS page gets its own full layout: OTIF sparkline hero + carrier table + exception banner + volume bar chart + POD aging
✦ Clean separation · TMS gets full real estate · Requires React Router (small dep)
B

Expandable TMS card — slide-in panel

Current "TMS · Active" tile gets a → expand button. Click it and a right-side drawer slides in over the page — showing OTIF trend, carrier ranking, exceptions, volume, POD aging. Overview stays visible on the left.
