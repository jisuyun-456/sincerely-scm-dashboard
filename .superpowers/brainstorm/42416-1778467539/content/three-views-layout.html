A2 — 페이지 내 섹션 구분 (스크롤)

TMS / WMS 페이지를 세 섹션(업무처리 → 운영 → 분석)으로 수직 분할. 탭 없이 스크롤로 전환.

장점

  • 탭 UI 없이 단순
  • 전체 맥락 한 번에 볼 수 있음
  • 개발 가장 쉬움

단점

  • 페이지 길이 길어짐
  • 분석 섹션까지 스크롤 필요

A3 — 최상위 탭 완전 분리 (비추천)

각 관점을 독립 페이지로. 탭이 8개가 되어 네비게이션이 복잡해짐. 참고용으로만 제시.

장점

  • 각 페이지 단순

단점

  • 탭 8개 — 너무 많음
  • 도메인 컨텍스트 분산

💡 추천: A1 (서브탭) — 최상위 네비게이션을 6탭으로 유지하면서 TMS·WMS 내부에서 업무처리 / 운영 / 분석을 빠르게 전환 가능. 현장에서 많이 쓰는 패턴.
